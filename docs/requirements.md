# RentGuard 需求文档

## 1. 项目概述

RentGuard 是一个面向租房合同的智能问答与风险提示系统。用户可以上传租房合同、房源描述、聊天记录等材料，系统对合同进行解析、检索和理解，回答用户关于押金、退租、维修、续租、违约责任等问题，并给出原文证据与风险提示。

## 2. 目标用户

- 签约前想快速审查合同风险的租客
- 已经签约、遇到押金或退租纠纷的租客
- 想弄清楚维修责任、费用承担、违约责任的普通用户

## 3. 产品目标

- 降低用户阅读租房合同的成本
- 自动识别常见高风险条款
- 基于合同原文给出可解释的问答结果
- 形成一个覆盖 LLM 应用、RAG、Agent、Eval 的完整项目

## 4. 核心使用场景

### 场景一：签约前审查

用户上传合同后提问：

- 这份合同有没有坑？
- 哪些条款对租客不利？
- 签之前我应该重点谈哪些地方？

### 场景二：押金纠纷

用户提问：

- 这种情况下房东可以扣押金吗？
- 合同里押金退还怎么写的？
- 帮我生成一段要求退押金的话术。

### 场景三：提前退租

用户提问：

- 如果我提前 1 个月退租，需要承担什么责任？
- 合同里写没写提前解约违约金？
- 能不能转租？

### 场景四：维修责任

用户提问：

- 热水器坏了谁负责修？
- 空调维修费是不是该我承担？
- 哪些属于正常损耗？

## 5. 功能需求

### 5.1 文档导入

- 支持 PDF 上传
- 支持 DOCX 上传
- 支持图片上传并进行 OCR
- 支持粘贴房源描述、聊天记录等文本

### 5.2 合同解析与结构化

- 提取合同原始文本
- 按“条”“款”“项”进行切分
- 为每段条款分配唯一 ID
- 抽取关键字段：
  - 租金
  - 押金
  - 租期
  - 支付周期
  - 违约责任
  - 解约条款
  - 维修责任

### 5.3 智能问答

- 接收自然语言提问
- 检索相关条款
- 生成基于证据的回答
- 返回结果包含：
  - 最终答案
  - 证据片段
  - 引用条款 ID
  - 不确定性说明

### 5.4 风险识别

- 自动检测常见租房风险：
  - 押金退还条件不明确
  - 违约金过高
  - 房东单方权利过大
  - 隐性服务费或管理费
  - 自动续租陷阱
  - 维修责任过度转嫁给租客
- 返回结果包含：
  - 风险标题
  - 风险等级
  - 风险解释
  - 对应条款

### 5.5 Agent 流程

系统根据用户问题自动路由到不同处理流程：

- 合同问答
- 风险审查
- 沟通话术生成
- 缺失信息追问

### 5.6 话术生成

- 生成面向房东或中介的沟通草稿
- 示例：
  - 退押金申请
  - 提前退租协商
  - 维修责任确认

### 5.7 评测能力

- 支持构建标注评测集
- 支持评测以下指标：
  - 回答正确率
  - 引用准确率
  - 忠实度
  - 风险识别召回率
- 支持导出 badcase

## 6. 非功能需求

- 常见问题响应时间控制在 8 秒以内
- 本地保存上传文件、解析结果和向量索引
- 每次问答保留日志便于回溯
- 在证据不足时明确表示“不确定”或“无法判断”

## 7. MVP 边界

MVP 包含：

- 单合同问答
- 中文租房合同解析
- 基于规则与大模型的风险识别
- 本地 Demo 部署

MVP 不包含：

- 多用户登录鉴权
- 在线法律法规检索
- 正式法律合规判断
- 长周期用户记忆

## 8. 成功标准

- 用户可以上传合同并完成至少 10 类常见租房问题问答
- 大部分回答能提供条款级引用
- 系统能在小规模测试集上识别常见高风险条款
- 项目可以在 5 分钟内完成端到端演示
