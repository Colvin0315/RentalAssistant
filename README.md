# RentGuard

RentGuard 是一个面向租房合同场景的智能问答系统，目标是帮助租客快速理解合同内容、识别高风险条款，并基于合同原文给出带证据引用的回答与沟通建议。

## 项目目标

- 支持租房合同 PDF、DOCX、图片上传与解析
- 支持围绕合同内容的智能问答
- 支持识别押金、违约、维修、续租等高风险条款
- 支持生成与房东、中介沟通的话术草稿
- 支持构建评测集并评估问答与风险识别效果

## MVP 范围

第一版聚焦以下能力：

- 单用户本地部署
- 面向中文租房合同
- 支持上传 1 份合同，可附加聊天记录或房源描述
- 基于 RAG 的合同问答
- 常见租房风险识别
- 基础评测与 badcase 记录

## 核心功能

1. 文档上传与解析
2. 条款切分与结构化抽取
3. 合同语义检索
4. 带证据引用的智能回答
5. 风险识别与解释
6. 沟通话术生成
7. 评测与错误案例分析

## 建议技术栈

- 前端：Next.js + Tailwind CSS
- 后端：FastAPI
- 向量库：FAISS
- 文档解析：PyMuPDF、python-docx、OCR
- 模型调用：OpenAI 兼容接口
- 数据库：SQLite

## 示例问题

- 这份合同里提前退租要赔多少钱？
- 合同是否写了押金退还条件？
- 空调坏了应该由谁负责维修？
- 哪些条款明显偏向房东？
- 帮我写一段向房东要押金的沟通话术。

## 注意事项

- 系统不提供正式法律意见
- 回答必须尽量区分“合同事实”和“模型建议”
- 能引用原文时必须优先给出引用
